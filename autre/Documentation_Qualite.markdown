# Documentation sur l'Assurance Qualité et la Qualité de Code

## 1. Qu'est-ce que l'assurance qualité ?
L'assurance qualité (AQ) est un processus systématique visant à garantir qu'un produit ou service répond aux exigences et standards définis. Dans le contexte du développement logiciel, cela inclut des pratiques comme les tests, les revues de code et l'utilisation d'outils pour maintenir la fiabilité et la performance.

## 2. Qu'est-ce que la qualité de code ?
La qualité de code se réfère à la clarté, la lisibilité, la maintenabilité et l'efficacité du code source. Un code de haute qualité est bien structuré, documenté, sans redondances inutiles et respecte les bonnes pratiques de programmation.

## 3. Quelle est la différence entre bug, erreur et défaillance ?
- **Bug** : Une erreur dans le code qui provoque un comportement inattendu du logiciel.
- **Erreur** : Une faute humaine commise lors de l'écriture du code (ex. syntaxe incorrecte).
- **Défaillance** : Le résultat observable d'un bug, où le logiciel ne fonctionne pas comme prévu.

## 4. Psychologie du test
La psychologie du test concerne l'état d'esprit des testeurs. Il est important d'adopter une approche objective, d'anticiper les cas d'utilisation variés et d'éviter les biais pour identifier efficacement les problèmes.

## 5. Outils de qualité
- **SonarQube** : Analyse statique du code pour détecter bugs, vulnérabilités et problèmes de qualité.
- **Flask8** : Extension pour Flask qui aide à respecter les conventions de style Python.
- **Black** : Outil de formatage automatique du code Python pour uniformité.
- **Pylint** : Vérifie la conformité du code aux bonnes pratiques et détecte les erreurs potentielles.
